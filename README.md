# SpendWise Offline

A mobile-first personal expense tracker that works as an installable web app on iPhone.

It includes category and meal-type pie charts, Day/Week 1–4/Month/Year views, ten-item pagination, editing, and Excel import/export.

## Privacy

Expense records are stored in the browser's local storage on the user's device. The repository and GitHub Pages contain only the application code; they do not receive or store transaction data.

## Publish with GitHub Pages

Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The expected address is: `https://hafizirshaadi.github.io/-spendwise-offline/`

## iPhone installation

Open the published address in Safari, tap **Share**, choose **Add to Home Screen**, and then tap **Add**. Open it once while online so its offline files are saved.

Use **Backup data** regularly. Browser data can be lost if Safari website data or the Home Screen app is removed.
